# 🚀 CampusFind – Lost & Found Portal

A full-stack web application designed to help students report, track, and claim lost and found items within a campus.

---

## 📌 Overview

CampusFind provides a centralized platform where users can:

* Report lost items
* Report found items
* Search items easily
* Claim items securely
* Admin can verify and manage claims

---

## 🧱 Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Bootstrap

### Backend

* Node.js
* Express.js

### Database

* MongoDB
* Mongoose

### Communication

* REST APIs (Fetch API)

---

## ✨ Features

### 👤 User Features

* User Registration & Login
* Report Lost Items
* Report Found Items
* Search functionality
* Claim items (with validation)

### 🔐 Admin Features

* View all items
* Approve / Reject claims
* Delete items
* Monitor system activity

---

## 🔄 System Flow

Active → Pending → Claimed → Returned

---

## ⚙️ How to Run the Project

### 1️⃣ Start MongoDB

---

### 2️⃣ Start Backend

cd backend
node server.js

---

### 3️⃣ Run Frontend

* Open `index.html` in browser
* (or use Live Server in VS Code)
